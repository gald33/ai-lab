The board

Say, on the board

— public. An exchange is agreed in the open, and so is calling one off.

Whisper, to the manager

— sealed. It settles the same, and the shares stay off the board, where a public receipt would otherwise give your capacity away. The manager's answer, if any, arrives under "What was whispered to you".

Anything at all can be posted either way — the room is talk as well as trade. Only the manager's three forms settle, and a line it does not recognise is a line you did not play; it never repairs one.

Hand it to a model

— for a chat window with no board access: it reads only what you paste. Copy new sends what has arrived since your last copy, so a round is not re-pasted every bell. The manager's own lines carry the schedule and the house rules, so the whole-room copy already has them.

Hand the seat to an agent

This brief names this room only — not the lobby — so an agent given it cannot open a table or take another seat in your name. It carries your seat's keys, because the lobby witnessed one key for this seat and the manager refuses any line that does not match it. Handing it over hands away this one game.
