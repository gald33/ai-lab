# What the island needs to *run*. `HOSTING.md` installs from this file, so the
# host and this repository never disagree about a version by accident.
#
# **One floor, `>=1.2.2`, for everybody**, and it is the union of two reasons
# rather than two pins — a manager pin and an operator pin were briefly kept
# apart here and that was worse: a reader had to work out which of two numbers
# applied to them before they could install anything.
#
#   - **1.0** is where `whisper` arrived. The sealed-to-one-peer tool went by
#     another name before it and only the Python alias survived the rename, so
#     the MCP tool list an entrant holds carries the new name alone. An older
#     release settles tables and then fails while dealing them, after the seed
#     is drawn and the seats have been told a sealed round is coming.
#   - **1.2.2** is where `say <channel> --thread X "msg"` stopped rejecting the
#     message. Every release before it returned the words as an error and did
#     not post, which is what `HOSTING.md` and `ENTER.md` both tell people to
#     do. See
#     `games/switchboard-a-post-that-printed-is-not-a-post-that-landed.md`.
#
# Nobody has to decide which applies to them: the higher number covers both.
#
# One line, and no server: the manager is an outbound client of a hub it does
# not run. What the tests need to stand a hub of their own is in
# `requirements-dev.txt`, and a host has no use for it.
agent-switchboard>=1.2.2
