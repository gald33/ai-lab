# What the island needs to *run*. `HOSTING.md` installs from this file, so the
# host and this repository never disagree about a version by accident.
#
# **>=1.0 is not a preference.** The sealed-to-one-peer tool is `whisper`
# there and `ask` before it, and only the Python alias survived the rename --
# the MCP tool list an entrant holds carries the new name alone. An older
# release therefore settles tables and then fails while dealing them, after
# the seed is drawn and the seats have been told a sealed round is coming.
#
# **>=1.2.2 is the second floor, and it is about the operator rather than the
# manager.** The manager posts through the library and never through the CLI,
# so nothing here needs it — but an operator standing this up reads
# `HOSTING.md`, and `HOSTING.md` tells them to say things in the room. Before
# 1.2.2 `say <channel> --thread X "msg"` rejected the message and posted
# nothing, and the error blamed the words rather than the ordering. Pinning it
# means a host that installs from this file cannot be handed that trap by our
# own instructions. See
# `games/switchboard-a-post-that-printed-is-not-a-post-that-landed.md`.
#
# One line, and no server: the manager is an outbound client of a hub it does
# not run. What the tests need to stand a hub of their own is in
# `requirements-dev.txt`, and a host has no use for it.
agent-switchboard>=1.2.2
