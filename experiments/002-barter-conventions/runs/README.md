# Runs

One record per run whose result is meant to be kept, numbered `NNN-slug.md`,
created from
[`templates/experiment/runs/RUN-TEMPLATE.md`](../../../templates/experiment/runs/RUN-TEMPLATE.md)
and committed **before** the run starts.

Specification, assumptions and hypothesis are written before and not edited
after; only the Outcome section is filled in later. A run that was specified
and never executed keeps its number and records why.

Why these exist, and the rule about not reading other experiments' grounding:
[`experiments/GROUNDING.md`](../../GROUNDING.md).
